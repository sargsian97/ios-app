## Слой расчётов

`web/src/domain/calc/` — готов (тренд веса v1/v2, BMR, TDEE, макросы, микронутриенты, e1RM, прогрессия, разминка, блины, объём), 157 тестов. Экраны подключают его по этапам 4–10.

## Временные константы, ждущие части 2

Все — в `web/src/domain/calc/constants.js`.

| Константа | Значение | Что значит |
|---|---|---|
| TREND_V1_ALPHA | 0,1 | доля нового взвешивания в EMA (v1) |
| TREND_V2_OUTLIER_HALF_WINDOW | 3 дня | ± окно медианы/MAD для выбросов (v2) |
| TREND_V2_OUTLIER_K | 3,5 | выброс, если отклонение > K·σ |
| TREND_V2_SIGMA_MIN | 0,5 кг | нижняя граница σ |
| TREND_V2_SMOOTH_HALF_WIDTH | 7 дней | ± окно локальной линейной регрессии (v2) |
| WEIGHT_RATE_DAYS / _MIN_DAYS | 14 / 7 | окно расчёта темпа веса |
| FORECAST_FLAT_KG_PER_WEEK | 0,05 | медленнее — прогноз даты не строится |
| MIFFLIN | 10 · 6,25 · 5 · +5 / −161 | формула Миффлина — Сан Жеора |
| CUNNINGHAM | 500 + 22 × безжировая масса | формула Каннингема |
| ACTIVITY_FACTORS | 1,2 / 1,55 / 1,725 | множитель BMR по активности (вероятно, завышены: онбординг спрашивает активность вне спорта) |
| KCAL_PER_KG_TISSUE | 7700 | ккал на 1 кг изменения массы |
| TDEE_FIRST_UPDATE_DAY | 3 | первое обновление расхода |
| TDEE_WINDOW_DAYS | 14 | окно энергобаланса |

| TDEE_MIN_INTAKE_DAYS / _SHARE | 3 / 0,5 | минимум дней с едой в окне |
| TDEE_RAW_MIN / MAX | 800 / 6000 | границы сырой оценки за день |
| CALORIE_FLOOR | М 1500 / Ж 1200; низкий М 1200 / Ж 1000 | нижний порог калорий |
| PROTEIN_G_PER_KG | 1,2 / 1,6 / 2,0 / 2,4 г/кг (по безжировой 1,5 / 2,0 / 2,5 / 3,0) | белок по уровню |
| DIET_TYPES | жиры 30 / 20 / 45 / 70 % ккал | сбалансированная / низкожировая / низкоуглеводная / кето |
