`web/src/domain/calc/` — готов (тренд веса v1–v3, BMR v1/v2, TDEE v1/v2, макросы, микронутриенты, e1RM, прогрессия, разминка, блины, объём и уровни, неделя программы и периодизация). Экраны подключают его по этапам 4–10.

## Применение учебного разбора (отчёт о публичных материалах адаптивного трекера)

| Часть | Статус |

| 1. Расчёты v2 по опубликованным формулам (BMR, старт с поправкой на цель, расход v2, тренд с интерполяцией, умное поддержание, предел 1200, сглаживание чек-ина, неполные дни по неделе, сдвиг при смене цели, БЖУ с приоритетом жиров) | готово |

## Что осталось по тренировкам (этапы 9–10)

- Несколько блоков программы в интерфейсе, перетаскивание дней, импорт/экспорт .xlsx, предложение обновить шаблон с diff после тренировки (этап 9). Модель данных блоки поддерживает.
- Графики по упражнению (лучший подход, e1RM), уровни по стандартам силы (нужны открытые таблицы), калибровка скорости утомления по первой неделе (этап 10).
- Доля собственного веса в упражнениях (`bodyweightShare`) пока не задана: вес тела сохраняется в тренировке, в объём не входит.
- Русские тексты инструкций к упражнениям (сейчас — английские из базы).
