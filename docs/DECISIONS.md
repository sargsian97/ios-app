# Решения

По одной строке: что было неясно или противоречило коду, что выбрано.

- 2026-10-16 · Стек: в репозитории уже было рабочее веб-приложение (PWA), поэтому продолжаем в нём, а не на Flutter из раздела 0 спецификации. Без Mac и без платного аккаунта Apple Flutter-приложение на iPhone не поставить.
- 2026-10-16 · Новые экраны пишутся на Preact + htm (одна библиотека в `web/vendor/`, без сборки); старые экраны из `web/app.js` работают внутри новой навигации, пока их не заменят.
- 2026-10-16 · Приложение перенесено из `docs/` в `web/`; `docs/` — для спецификации и заметок. Адрес на GitHub Pages не изменился.
- 2026-10-16 · Вместо Drift/SQLite — та же IndexedDB (`journal`), что и раньше, с версией схемы в `meta/schema` и миграциями. Старые записи при миграции не удаляются.
- 2026-10-16 · Аккаунт: только локальный режим, без входа. Для синхронизации оставлен интерфейс `SyncProvider` с локальной реализацией.
- 2026-10-16 · Недоступно в PWA на iPhone: Apple Health, виджеты, Live Activity, уведомления при закрытом приложении, альтернативные иконки, быстрые действия на иконке. Health Connect есть только на Android. Таймер отдыха — звук и не гаснущий экран, пока приложение открыто.
- 2026-10-16 · Ключ USDA FoodData Central вводится в настройках и хранится только на телефоне, как ключ Claude; Open Food Facts работает без ключа.
- 2026-10-16 · Существующие ИИ-функции (фото еды, автозаполнение через ключ Claude) остаются; новые ИИ-функции — только интерфейсы и заглушки «скоро» до отдельного решения. Лимиты ИИ применяются и к существующим функциям.
- 2026-10-16 · Тесты — встроенный `node:test` без зависимостей; CI запускает их перед публикацией на Pages.
- 2026-10-16 · Строки старых экранов (`web/app.js`) пока остаются в коде на русском; через `t()` идут все новые экраны. Старые экраны переводятся на `t()` по мере замены.
- 2026-10-16 · Первая вкладка названа «Обзор» (как в «Здоровье» на iPhone), а не «Дашборд»; экран — короткий обзор за сегодня до этапа 11.
- 2026-10-16 · Профиль (спецификация: пол, ДР, рост, единицы, тема, согласия) — один документ `profile/me`; рост переносится из настроек журнала миграцией 2.
- 2026-10-16 · Резервная копия переехала в «Ещё → Настройки»; формат файла 2 включает все коллекции и версию схемы, старые копии (формат 1) после загрузки проходят миграции.
- 2026-10-16 · В «+» штрихкод и быстрое добавление помечены «скоро» до этапа 3; «Еда» и «Фото еды» пока открывают добавление из старого журнала.
- 2026-10-16 · TDEE: 0 ккал без отметки «голодание» считается незаписанным днём; день голодания — всегда 0. Добавлен третий повод для hold — `short_window` (тренд есть меньше чем за 2 дня окна).
- 2026-10-16 · Прогрессия: при выборе цели берётся нижняя граница диапазона повторов (самый тяжёлый доступный вес, с которым она достижима при целевом RIR). Усталость — доля от цели.
- 2026-10-16 · Блины: из точных раскладок выбирается та, где меньше блинов, затем — где блины тяжелее.
- 2026-10-16 · Микронутриенты: потолок магния не задан (UL относится к добавкам); натрий — 2300 мг (уровень снижения риска, не UL); насыщенные жиры и добавленный сахар — 10 % калорий; кофеин и алкоголь — не из DRI.
