# Спецификация: приложение «питание + тренировки» (часть 1 — функции)

> **Для того, кто пишет код (человек или Claude).**
> Это спецификация функций личного учебного приложения, которое объединяет трекер питания с адаптивным коучем калорий и трекер тренировок с умной прогрессией.
> Ориентир — функциональность двух существующих приложений (MacroFactor и MacroFactor Workouts), изученная по их публичным APK. **Код, тексты, базы данных, картинки и бренд оттуда не переносятся**: всё пишется своим кодом, со своим дизайном и своими текстами, на открытых данных.
> **Часть 2** (будет позже) — точные формулы расчётов: тренд веса, расход энергии, макросы, автопрогрессия. Пока её нет, реализуй расчёты по описаниям из раздела 2.4 и 3.4 и вынеси коэффициенты в константы, чтобы их легко было заменить.

## 1. Питание

### 1.1 Онбординг
Пошаговый мастер. Каждое поле влияет на стартовую оценку расхода калорий:
- пол, дата рождения (18+), рост, вес, **% жира** (можно выбрать визуально по картинкам телосложения), максимальный вес за жизнь, динамика веса за последние недели (худел / набирал / стабилен);
- активность вне спорта: сидячий / умеренный / очень активный, с ориентиром по шагам (<5 000, 5–15 000, >15 000);
- тренировок в неделю, опыт кардио и силовых (≤1 года / 1–4 года / 4+ лет), любитель или профессиональный спортсмен;
- экран стартовой оценки расхода с объяснением, как она получена;
- подключение Health Connect / Apple Health, согласие с медицинским дисклеймером.

### 1.2 Цель и программа (ядро коуча)
**Цель:** похудеть / поддерживать / набрать; целевой вес; темп в **% массы тела в неделю**; дата достижения; стиль прогноза (по данным веса / по цели / смешанный). Для поддержания — коридор веса. История целей.

**Программа**, три стиля:
1. **Coached** (решает коуч): распределение калорий (ровно / дни с повышенной калорийностью); нижний порог калорий (стандартный / низкий / игнорировать); тип диеты (**сбалансированная, низкожировая, низкоуглеводная, кето**); белок (**низкий / умеренный / высокий / очень высокий**); тип тренировок.
2. **Collaborative**: пользователь задаёт ограничения, коуч подстраивает.
3. **Manual**: пользователь сам задаёт калории и БЖУ (одинаково или по дням недели); расход и прогресс считаются, но цели не меняются автоматически.

### 1.3 Еженедельный чек-ин
Раз в неделю в выбранный день, можно раньше. Собирается из модулей, которые появляются по ситуации; каждый модуль можно отключить:
- **Введение**: разовое объяснение системы.
- **Взвешивание**: предложить взвеситься, показать историю.
- **Частичный лог**: найти дни, похожие на неполные, предложить пометить их (они исключаются из расчёта расхода).
- **Голодание**: подтвердить дни голодания (0 ккал — настоящий ноль, а не пропуск).
- **Перерыв в логировании**: расход замораживается (hold) и потом возобновляется.
- **Обновление программы**: новые калории и макросы с объяснением изменений.
- **Уведомления**: служебные сообщения.

### 1.4 Алгоритмы (суть; точные формулы — в части 2)
- **Тренд веса**: сглаживание ежедневных взвешиваний. V1 — экспоненциальное скользящее среднее только по прошлым точкам. V2 — робастный двусторонний сглаживатель (устойчив к выбросам, меньше запаздывает, может пересматривать прошлые точки).
- **Расход энергии (TDEE)**: адаптивный, по энергобалансу: среднее потребление − (изменение тренд-веса × энергоплотность ткани) / дни, со сглаживанием по времени.
  - старт: BMR × активность; первое обновление на 3-й день; устойчивая оценка за 20–30 дней;
  - нужно хотя бы одно взвешивание за 7 дней, иначе hold;
  - частичные дни исключаются, дни голодания идут как 0;
  - опции: ускорение обновлений по шагам; поправка на ожидаемое влияние смены цели;
  - режим «фиксированный TDEE» (ввод вручную).
- **BMR**: формула по безжировой массе (Cunningham) и формула по росту, весу, возрасту и полу (например, Mifflin-St Jeor).
- **Макросы**: белок = уровень × масса (или безжировая масса); жиры и углеводы по типу диеты; вариант «углеводы как остаток»; нижний порог калорий.
- **Микронутриенты**: автонормы по возрасту и полу (беременность и лактация опционально): минимум, цель и верхний предел для каждого нутриента; ручная правка.

### 1.5 Дневник питания
- **Таймлайн** по часам: видимые часы настраиваются, пустые можно скрывать, итоги БЖУ за каждый час, «+» у каждого часа. Виды: день / неделя / месяц.
- **Классический** список приёмов пищи.
- Действия: множественное выделение, копировать, вставить, переместить (на дату и час, в том числе на несколько дат), удалить, очистить день, добавить из истории; свайпы; перетаскивание; заметка к дню.
- Баннер «съедено / осталось» (несколько вариантов), полоса статуса дня, итог дня.
- Отметки дня: голодание, частичный лог, ручное переопределение итога; менеджер данных питания для массовой правки задним числом.

### 1.6 Добавление еды («тарелка» на несколько продуктов)
- **Поиск**: общая база, брендовые продукты, Open Food Facts, USDA, история, свои продукты и рецепты, избранное, фильтры.
- **Штрихкод** + ручной ввод номера; если продукта нет, предложить сфотографировать упаковку.
- **Быстрое добавление**: только калории и макросы.
- **ИИ**: фото тарелки → продукты с порциями; текстовое описание еды; фото этикетки → нутриенты; вставка текста с разбором.
  Конвейер: распознать, что на фото → сгенерировать кандидатов → найти похожие в своей базе → выбрать лучшие совпадения → подобрать единицы порции. Результаты показывать потоком, по мере готовности.
- **Свой продукт**: название, бренд, порция (вес / объём / штуки), формат этикетки, фото; ИИ-импорт по фото упаковки; при заданном объёме порции — автоконвертация единиц объёма.
- **Рецепты**: ингредиенты (в том числе вложенные рецепты), шаги, время, вес готового блюда. Импорт по ссылке (сначала структурированная разметка страницы, иначе LLM), по фото, по описанию.
- Поделиться продуктом или рецептом ссылкой.
- Избранное, «любимые единицы» (закреплённые первыми), своя цифровая клавиатура, метрические и имперские единицы.
- Карточка продукта: выбор порции, влияние на дневной бюджет.

### 1.7 Нутриенты
Калории, БЖУ; клетчатка, сахара, добавленный сахар, крахмал, net carbs; насыщенные / моно / поли / транс-жиры, омега-3, омега-6, холестерин; витамины A, C, D, E, K, группа B (B1, B2, B3, B5, B6, B12, фолат, холин); кальций, железо, магний, фосфор, калий, натрий, цинк, медь, марганец, селен; незаменимые аминокислоты; вода, кофеин, алкоголь. У каждого — своё короткое описание.

**Обозреватель нутриентов**: фокус на нутриенте, распределение по времени суток, история целей, полнота данных, топ-источники.

### 1.8 Дашборд (настраиваемый)
- Секции: питание, тело, общее, привычки, инсайты. Карточки добавляются, удаляются, переставляются; плотность карточек.
- Верхние «фокусы»: питание за день, за неделю, энергобаланс.
- Экраны подробностей: тренд веса, вес с весов, расход, энергобаланс, макросы, прогресс к цели, шаги, замеры, фото, цикл, привычки, сравнение всех метрик.
- Графики: периоды 7 / 14 / 30 дней / месяц / всё время, усреднение, маркер-трекбол, сравнение.

### 1.9 Тело, привычки, здоровье
- Вес и % жира (в том числе со смарт-весов через интеграции).
- Обхваты: шея, плечи, грудь, талия, бёдра, а также руки и ноги L/R; отношения талия/рост и талия/бёдра.
- Фото прогресса: спереди, сбоку, сзади; галерея; «до/после».
- Шаги (из Health Connect / Apple Health).
- Менструальный цикл.
- Привычки: серии логирования еды, взвешиваний, тренировок; годовая тепловая карта.

### 1.10 Настройки и сервис
- Единицы (вес, рост, ккал/кДж, расстояние, 12/24 ч), тема и палитры, альтернативные иконки.
- Видимость данных (скрыть ненужные нутриенты и метрики).
- Настройки дневника (карточки, баннер, время, ярлыки); панель из 4 своих кнопок-ярлыков; быстрые действия на иконке.
- Виджеты: прогресс (полоса / кольцо), «осталось», несколько нутриентов.
- Интеграции Health Connect / Apple Health (вес, жир, питание, вода, шаги — чтение и запись).
- Экспорт в Excel: быстрый и детальный; дневник, метрики, библиотека, тренировки; выбор периода.
- Выборочное удаление данных и удаление аккаунта.
- Туториалы (со сбросом).
- Пасхалка: мини-игра в самом низу экрана настроек (по желанию).

## 2. Тренировки

### 2.1 Онбординг и генератор программы
- Цель: **сила / гипертрофия / обе**.
- Опыт и простые тесты силы (жим, подтягивания, отжимания, брусья на N повторов).
- Где тренируется: шаблоны залов (коммерческий, гаражный, домашний, полностью оборудованный) и доступное оборудование.
- Дней в неделю (**2–6**), время на тренировку (от 20 до 120+ минут).
- Сплит: фулбади, верх/низ, верх/низ/фулбади, тяни-толкай, push/pull/legs, PPL ×2, присед/тяга бедром/жим/тяга, гибриды.
- Приоритет мышц (больше / меньше внимания).
- **Периодизация**: без неё / линейная (повторы ↓, вес ↑) / обратная / чередование тяжёлых и лёгких недель.
- **Делоад**: в начале или в конце блока, или без него; повторить блок один раз или бесконечно.

Экран генерации показывает этапы: оборудование → опыт → приоритеты мышц → сплит → подбор упражнений → оптимизация под время.
Логика подбора: у каждого упражнения есть уровень рекомендованности отдельно для силы и для гипертрофии и роль (основное многосуставное / второстепенное многосуставное / изоляция / кор). Генератор выбирает по паттерну движения, доступному оборудованию, «группам исключения» (не ставить два почти одинаковых упражнения) и предусловиям (например, подтягивания с весом — только если получаются чистые).

### 2.2 Конструктор программ
- Блоки, дни (тренировка / отдых), переименование, перенос.
- Упражнения с целями: подходы, диапазон повторов, **RIR**, тип подхода; **суперсеты и круговые**; свои секции (разминка / основная / финишер).
- Drag & drop тренировок и блоков, библиотека, архив, дублирование, цвет и иконка программы, заметки.
- Импорт и экспорт **.xlsx** (свой формат).
- После тренировки с изменениями — предложить обновить план с показом diff.

### 2.3 Активная тренировка
- Метрики подхода: вес, вес-помощь (гравитрон), повторы, время, дистанция; варианты «на каждую сторону».
- Типы подходов: обычный, до отказа, дроп-сет, мио / рест-пауза; частичные повторы; лево и право отдельно.
- **RIR** со шкалой-подсказкой; автоподстановка RIR из программы.
- Предыдущие значения: из любой тренировки или только из этой программы.
- **Таймер отдыха**: по типу упражнения, свой для упражнения, между сторонами, после разминки, между упражнениями; уведомления звуком и вибрацией; экран блокировки / Live Activity; не гасить экран; общий таймер тренировки.
- Автопрокрутка суперсетов, автопереход к следующему упражнению, скрытие выполненных подходов.
- Замена упражнения с учётом оборудования зала, пропуск, добавление посреди тренировки, заметки (к сессии, к упражнению, к программе).
- Учёт веса тела в упражнениях с собственным весом (из тренд-веса).
- Итог тренировки, рекорды, правка истории.

### 2.4 Умная прогрессия (ядро тренировок; формулы — в части 2)
- Неделя 1 — подбор стартовых весов и калибровка индивидуальной скорости утомления.
- Модель:
  1. по выполненным подходам (вес × повторы × RIR) оценивается 1ПМ и «профиль силы»;
  2. моделируется накопление усталости от подхода к подходу;
  3. на следующий подход и тренировку рассчитывается цель внутри диапазона повторов, вес округляется до доступных в зале шагов;
  4. если одной сменой веса в диапазон не попасть — расширить диапазон повторов (настраивается, с предупреждением), иначе линейная прогрессия.
- Опции: автозаполнение посреди тренировки, предпочитать вес предыдущего подхода.
- Временная формула до части 2: e1RM = вес × (1 + (повторы + RIR) / 30); цель = e1RM / (1 + (целевые_повторы + целевой_RIR) / 30) − поправка на усталость; округлить до доступных блинов.

### 2.5 Разминка
- Умная разминка: подходы в процентах от рабочего веса или 1ПМ; если рабочий вес слишком мал, разминку не строить.
- Схемы разминки: по умолчанию и для отдельных упражнений.
- Автоматизация: добавлять разминку, только если мышечная группа ещё не работала в этой тренировке; упрощать набор блинов для разминки.

### 2.6 Залы и оборудование
- Несколько профилей залов с иконками, выбор зала на тренировку, дублирование.
- Инвентарь по категориям (свободные веса, грифы, резинки, кабели, блочные тренажёры, тренажёры под блины, скамьи и стойки, свой вес, аксессуары).
- Блины (обычные, бамперные, цвета, смешанные единицы), веса грифов, гантельные ряды, **весовые стеки** (диапазоны, микродовески); **ИИ-скан стека тренажёра по фото**.
- **Калькулятор блинов** (на сторону / одна сторона), превью грифа, смещение веса.
- Переопределение весов для конкретного упражнения.

### 2.7 Библиотека упражнений
- Атрибуты упражнения: синонимы, тип (многосуставное / изоляция / кор), паттерн движения, область (верх / низ / кор / всё тело), латеральность, основные и вторичные мышцы (с группировкой в ~20 показательных групп), суставные действия, амплитуда и стабильность (шкалы 1–5), доля собственного веса, оборудование, предусловия, группы исключения.
- Карточка: инструкция, видео / превью, карта мышц (SVG), история, рекорды.
- Свои упражнения, архив, поиск с синонимами, фильтры.
- **Данные — из открытых источников** (wger, free-exercise-db) плюс свои тексты.

### 2.8 Аналитика тренировок
- Недельные тренировки, свежие рекорды.
- Подходы и объём по мышечным группам (средние за неделю, с учётом основных и вторичных мышц), топ упражнений по подходам и объёму.
- Графики лучшего подхода (объём / повторы / время / дистанция), максимальный вес, e1RM.
- **Уровни**: общий и по мышцам (сравнение силы со стандартами).
- Запись тренировок в Health Connect / Apple Health.

── Тело ──

── Тренировки ──

## 4. Одно приложение вместо двух

**Навигация:** Дашборд · Питание (таймлайн) · «+» (поиск / скан / ИИ / быстро) · Тренировка · Ещё.

Что даёт объединение:
- тренировки сразу видны в коучинге питания (одна база);
- фаза диеты связана с целью тренировок: набор → гипертрофия + профицит, сушка → сила + дефицит; генератор программы учитывает текущую фазу;
- **один** еженедельный чек-ин: калории + обзор прогресса в зале (рекорды, объём по мышцам);
- вклад собственного веса в упражнениях берётся из тренд-веса.

## 5. Порядок разработки (MVP → полное)

1. Аккаунт, профиль, единицы, тема.
2. База продуктов (Open Food Facts + USDA) с поиском, дневник-таймлайн, быстрое добавление, штрихкод.
3. Вес → тренд веса (EMA), дашборд с графиком.
4. Онбординг + BMR + стартовые цели макросов.
5. Адаптивный TDEE + еженедельный чек-ин (ядро ценности).
6. Свой справочник упражнений + логирование тренировок + таймер отдыха.
7. Залы и оборудование + калькулятор блинов + разминка.
8. Умная прогрессия (e1RM + RIR + усталость).
9. Генератор программ.
10. ИИ: фото еды, описание текстом, этикетка, импорт рецепта по ссылке, скан стека — с лимитами.
11. Нутриенты и микроцели, фото прогресса, обхваты, привычки, экспорт, виджеты, интеграции.

Правило для расчётов: каждая формула (тренд, TDEE, BMR, макросы, e1RM, прогрессия, разминка, блины) — отдельная чистая функция с юнит-тестами, коэффициенты — в константах. Так часть 2 можно будет подставить без переписывания UI.
