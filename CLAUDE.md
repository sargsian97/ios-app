# Журнал: питание + тренировки

Личное приложение для iPhone. Это веб-приложение (PWA): ставится через Safari на экран «Домой», работает офлайн, данные хранятся на телефоне в IndexedDB. Сборки нет — статические ES-модули.

## Где что лежит

- `docs/SPEC_функции_питание_и_тренировки.md` — спецификация, часть 1 (функции, экраны, модель данных, порядок разработки). Часть 2 (точные формулы) придёт позже.
- `docs/DECISIONS.md` — решения по неясным местам спецификации, по одной строке. Пополняй, а не угадывай молча.
- `docs/PROGRESS.md` — какие этапы готовы, что осталось, какие временные константы ждут части 2. Обновляй в конце каждой сессии.
- `web/` — само приложение, публикуется на GitHub Pages из `main` (`.github/workflows/pages.yml`).
  - `web/app.js` — старый журнал (экраны тренировок, питания, замеров, истории). Заменяется новыми экранами по этапам.
  - `web/src/` — новый код: `ui/` (экраны на Preact + htm), `data/` (хранилище, миграции, репозитории), `domain/calc/` (расчёты), `services/`, `i18n/`.
  - `web/sw.js` — офлайн-кэш. **При каждом выпуске меняй `VERSION`** (и `APP_VERSION` в `web/src/version.js`); список файлов `SHELL` обновляет `npm run shell` (тест `tests/sw.test.js` проверит).
- `tests/` — юнит-тесты (`node:test`).

## Правила по контенту

- Весь код, тексты интерфейса, иконки и иллюстрации — свои. Ничего не копируй из MacroFactor и MacroFactor Workouts: ни тексты, ни базы, ни картинки, ни бренд, ни их серверы и ключи.
- Продукты — Open Food Facts и USDA FoodData Central. Упражнения — открытые базы (free-exercise-db, wger) с проверенной лицензией; источник и лицензия — в README.
- Подписки, paywall и рекламы нет. Лимиты на ИИ-функции есть (счётчики день / неделя / месяц, значения в конфиге).
- Ключи API — только вводом в настройках на телефоне (хранятся локально). Никогда не в коде и не в git.
- Интерфейс на русском, все новые строки через `t()` из `web/src/i18n/`. Единицы метрические по умолчанию, имперские через настройку; в базе всегда метрические (кг, см, ккал, км).
- Маленькие шаги: каждый этап — рабочее состояние, зелёные тесты, отдельный коммит.

## Расчёты

- Все расчёты — в `web/src/domain/calc/`: только чистые функции (данные на входе, результат на выходе), без базы, DOM и UI.
- Все коэффициенты и пороги — в `web/src/domain/calc/constants.js` с пометкой «временное значение, уточнится в части 2 спецификации». Не подбирай «точные» коэффициенты по догадкам.
- Версия алгоритма передаётся параметром (`version: 'v1'`), новая версия добавляется рядом, а не вместо.
- У каждой функции юнит-тесты, включая крайние случаи: пустые данные, один день, пропуски, выбросы, нулевые калории, вес ниже минимального блина.

## Запуск и тесты

```sh
npm test          # юнит-тесты, Node 22+, без зависимостей
npm run serve     # http://localhost:8000 — приложение из web/
```

Проверка в браузере — Playwright с профилем iPhone (в облачной сессии он уже установлен в `/opt/node-tools`):

```sh
node tests/e2e/shell.e2e.mjs light   # или dark; снимки — в .e2e-shots/
```

Для проверок используй выдуманную копию `tests/fixtures/backup-sample.json`; личные данные пользователя в git не кладём.
