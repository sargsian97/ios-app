# Журнал тренировок и питания

Приложение для iPhone, которое ставится на экран «Домой» через Safari и открывается на весь экран, как обычное приложение. App Store и Mac для этого не нужны. Работает без интернета, данные хранятся на телефоне.

Внутри то же, что было в журнале в Claude:

- **Тренировки**: дни A/B/C по шаблонам, подходы, таймер подхода и отдыха (пока он идёт, экран не гаснет), подсказки «прошлый раз», кардио, шаги и расчёт расхода калорий.
- **Питание**: кольцо калорий, БЖУ и клетчатка с разбивкой белка на животный и растительный, «Мои продукты». Распознавание еды по фото и автозаполнение работают через Claude.
- **Замеры**: вес, обхваты, графики, календарь, расчёт процента жира.
- **История**: календарь дефицита и профицита, итоги за неделю и месяц.
- **План**: шаблоны тренировок и настройки, включая ключ Claude и резервные копии.

## Как поставить на iPhone

1. Откройте адрес приложения в **Safari**. В Chrome и других браузерах это не сработает.
2. Нажмите «Поделиться» и выберите «На экран „Домой“».
3. Запустите «Журнал» с экрана «Домой».
4. На первом экране нажмите «Выбрать файл» и укажите файл `journal-backup-….json`, чтобы перенести данные из старого журнала.

## Ключ Claude (фото и автозаполнение)

1. Зайдите на [console.anthropic.com](https://console.anthropic.com), откройте API Keys и создайте ключ. Нужен баланс на счёте: оплата идёт за каждый запрос, обычно это доли цента.
2. В приложении откройте «План → Настройки → Claude» и вставьте ключ.

Ключ хранится только на телефоне и уходит напрямую в api.anthropic.com. В резервные копии он не попадает.

## Резервные копии

Все данные живут в памяти Safari на телефоне. Раз в неделю нажимайте «План → Настройки → Сохранить копию» и сохраняйте файл в «Файлы» или iCloud Drive. Из этого файла всё восстанавливается на новом телефоне.

## Для разработки

Приложение лежит в `docs/`: статические файлы без сборки.

| Файл | Что внутри |
|---|---|
| `index.html` | оболочка, мета-теги для экрана «Домой» |
| `app.js` | вся логика и интерфейс (перенесены из журнала) |
| `store.js` | хранилище в IndexedDB, импорт и экспорт |
| `ai.js` | вызовы Claude API: питательность, фото, перевод |
| `sw.js` | офлайн-кэш |
| `vendor/anthropic-0.131.0.mjs` | Anthropic TypeScript SDK, собранный для браузера |

Чтобы запустить локально, выполните `cd docs && python3 -m http.server 8000`.

**При каждом выпуске меняйте `VERSION` в `docs/sw.js`.** Иначе телефон продолжит показывать старую версию из кэша. После изменения версии в приложении появится плашка «Доступна новая версия».
